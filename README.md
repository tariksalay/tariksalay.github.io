# Alternative portfolio design — preview only

This branch proposes a visually distinct version of [tariksalay.github.io](https://tariksalay.github.io/), focused on senior data analytics and data engineering.

### Design approach
- Dark technical visual identity and mint accents
- Responsive, accessible layout with keyboard focus states
- Illustrative CRM/ERP → Microsoft Fabric → SQL/PySpark → Power BI architecture
- Transparent, accurately scoped public project descriptions and engineering experience
- Single static `index.html` without build tooling

### Preview and release
The live website remains on the `master` branch. Review the draft pull request before merging. To run locally, open `index.html` in a browser. Test at mobile and desktop widths.

Original Claude design backup: `backup/claude-portfolio-2026-10-15`. Current live version is also preserved through Git history.

### Note
The architecture graphic is illustrative and not a deployment diagram or a public release of employer systems. Business achievements are described qualitatively; no unverified metrics have been introduced.
